LetterTyper 本地练习

这是电脑本地的公开示例练习页，不是批改网。不需要登录，不上传、不保存输入内容，也没有提交表单。请先让工具保留默认的两行示例。

  1. 回到工具，点“测试前 6 个字符”。
  2. 在倒计时结束前回到本页，点击下面左侧空白框，切到英文输入法并松开快捷键。
  3. 看到 Hello 后保留它；回工具勾选确认，点击继续；倒计时内回到左侧框并按 Ctrl+End 到文字末尾。
  4. 全部输入完成后再点击“检查练习结果”。

尚未检查。先测试，再确认并继续。

② 完成后应得到这两行

Hello world! This is a public typing demonstration.
Please test a few characters before continuing.

短文本测试只会先输入 Hello 和一个空格。全文还有末尾换行；检查按钮会核对它。

要从头重来：先暂停工具，清空左边，再回工具点“重置进度”。单独清空左边不会重置工具。
