## 如何复现

1. 完整解压，命令提示符中进入含 `start.cmd` 的目录，执行 `verify.cmd`；不应产生键盘事件。
2. 执行 `start.cmd`，应显示公开样例和 `Hello␠` 测试预期。
3. 源码包中可用 Windows PowerShell 5.1 的 STA 进程加载 `scripts/Capture.ps1` 生成文档截图，`scripts/KeyboardSmoke.ps1` 运行专门的按键测试窗口。它们要求 `-Root` 指向项目根目录；后者会发送真实模拟按键，仅在自己的测试窗口处于前台且文本框获得焦点时发送。
4. 若设备允许脚本文件执行，可用 `powershell.exe -NoProfile -STA -File scripts\Capture.ps1 -Root .` 或相应的 KeyboardSmoke 脚本。若执行策略或组织策略拒绝，停止并联系管理员；不要为运行测试更改系统安全策略。

上述自动检查不是网页自动化测试。发布给其他人时应保留这些边界，不把“编译通过”描述为“所有页面输入成功”。
