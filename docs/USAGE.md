# LetterTyper 使用教程

## 1. 解压并运行

完整解压便携 ZIP，找到最内层包含 `start.cmd` 的目录，双击它。不要只把 `start.cmd` 单独拿出来，程序还需要同目录的 C# 源码和 `examples/sample.txt`。源码 ZIP 的启动方法相同。

运行环境为 Windows 10/11、Windows PowerShell 5.1、.NET Framework 4.8 和正常交互桌面。无需管理员、浏览器插件或云端服务。PowerShell 需要 FullLanguage 模式且允许动态编译；若组织策略阻止，请联系管理员，不要关闭安全策略。

启动时可能出现一个命令窗口，随后出现 LetterTyper 界面。命令窗口承载程序，运行期间不要关闭；关闭窗口会退出工具。若启动失败，先读命令窗口中的错误提示。

## 2. 准备自己的英文文本

使用记事本保存 UTF-8 `.txt`。支持普通英文字母、数字、ASCII 标点、普通空格和换行。文件必须为 1–100000 个字符，大小不超过 400000 字节。UTF-8 BOM 可以接受，CRLF/CR 会规范为 LF，末尾换行会保留并发送。

请把弯引号改成直引号、长破折号改成普通减号，移除制表符和不换行空格。工具会拒绝不支持的字符，不会静默删除。内容显示在预览框中，选择文件前请确认周围没有不应看到文本的人。

自己的文本建议放在项目的 `data/` 目录或项目之外。不要替换将公开分发的 `examples/sample.txt`。程序只把加载后的文本保留在内存，不复制到项目，不记录文件路径或输入日志；系统文件选择对话框可能自行维护最近使用记录。

## 3. 打开正确页面

自行在浏览器登录并进入允许录入的多行编辑页面。默认匹配浏览器进程和标题中的“批改”或 `pigai`，可用于尝试批改网作文正文编辑页；成绩点评页通常没有可输入正文框。程序不自动打开网站或登录。

确认浏览器不是以管理员权限运行，工具和目标使用相同普通权限。切换为英文输入法，关闭可能改变文本的自动替换功能。确认输入框已有内容是否需要备份；需要从头输入时，自己清空正文。

**仅用多行正文框。** 每个换行会发送 Enter；在单行表单中可能触发网站提交。工具不会识别这种网站行为。

## 4. 先做短文本测试

1. 点击“选择本机文本”，查看预览是否正确。
2. 查看“测试应显示”的内容。默认示例前六字符是 `Hello `，末尾是空格；界面以 `␠` 标识空格、`↵` 标识换行。
3. 点击测试按钮，在默认 8 秒内切回目标网页，点击正文框，松开 Alt/Ctrl/Shift/Win 等键。
4. 倒计时结束后只会发送测试部分，并自动暂停。
5. 肉眼检查字母大小写、空格和换行。若不正确，停止并排查，不要勾选确认。

测试内容已经写入网页，续输时不要删除它。若自行删除了测试文字，请重置工具进度、清空正文并重新测试。

## 5. 继续与暂停

测试正确后返回工具，勾选“我已确认网页测试文字正确”，点击“继续输入”。倒计时内返回同一正文框，将光标放到已输入文字末尾。工具从测试部分之后继续。

输入期间不要切换窗口、标签页或移动光标。需要暂停时，稍按住 Esc，或直接切换到工具窗口。状态轮询存在间隔，极短按键可能未被检测。窗口标题变化也会暂停；同标题标签页变化可能无法检测。

继续之前把光标重新放在已输入文字末尾。若网页漏字、选区改变、自动格式化或人工修改影响了正文，请先核对实际内容；工具不会回读网页。无法确定进度时，备份当前正文，清空后重置并重新输入。

“重置进度”只重置工具，不会删除网页内容。关闭程序或重新选择文件也会重置进度。

## 6. 检查后自行提交

“已发送全部文字”只说明系统调用已完成，不代表网页接收完整。请核对全文、分段、标点、词数及保存状态，再使用网站自身的提交按钮。工具没有自动提交功能。

## 7. 可选配置

把 `config.example.json` 复制为 `config.local.json` 后再修改。修改后需关闭并重新启动工具。字段说明见 README；请保留较具体的窗口标题关键词，不使用通配符。不要在配置里存密码、Cookie、Token 或学生信息。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 找不到工具窗口 | 按 Alt+Tab 找“LetterTyper · 本机逐字输入”；或检查任务栏。避免重复启动多个实例。 |
| 双击后闪退/出现错误 | 从命令提示符进入目录后运行 `start.cmd`，阅读错误。检查是否完整解压、文件完整、PowerShell 和 .NET 可用。 |
| FullLanguage、Add-Type 或应用控制被拒绝 | 设备策略不允许该运行方式。联系管理员；不要关闭系统防护。没有其他平台或管理员启动保证。 |
| 继续按钮是灰色 | 先完成测试并勾选确认；测试已输入完整短文本时无需继续。 |
| 前台窗口不匹配 | 检查页面标题、浏览器进程名及本地配置；倒计时结束前要点击网页正文框。 |
| 没文字、漏字、输入成中文 | 检查焦点和英文输入法，将间隔调到 150–300 毫秒，再以少量文字测试。网站也可能拒绝模拟输入。 |
| 提示不支持字符 | 文件内可能含弯引号、中文、制表符、emoji 等。请改为 ASCII 英文和普通换行，保存 UTF-8。 |
| 在其他页面输入失败 | 修改本地配置只改变匹配规则，不保证页面兼容。先确认页面允许自动录入，再单独测试。 |
| 计数与网页文字不一致 | 计数只记录发送调用。请人工核对；必要时备份、清空、重置并重新开始。 |
| 自动暂停 | 页面标题或前台窗口变化、快捷键仍按住、Esc 或发送失败都可能暂停。查看状态文字。 |
| 怎么卸载 | 关闭工具后删除解压目录即可；自己的文件自行保留。程序不安装服务或浏览器扩展。 |

## 本地验证和分享

运行 `verify.cmd` 可做不发送按键的检查。源码包中的 `scripts/KeyboardSmoke.ps1` 会打开专门的测试窗口，涉及真实模拟按键；不要把普通 `verify.cmd` 与它混淆。验证状态见 `VALIDATION.md`。

发布时只分享 `package.cmd` 生成的 ZIP，不要直接压缩整个使用目录。即使 `.gitignore` 忽略了某文件，Git 已经跟踪的文件仍可能被上传，因此上传前仍需检查暂存区和仓库历史。
