# 隐私与权限说明

## 程序读取和使用的数据

- 用户通过文件对话框主动选择的 UTF-8 文本内容，仅存放于本次进程内存并显示在预览框中。
- 默认公开演示文件；若存在 `config.local.json`，读取其中的倒计时、间隔和窗口匹配规则。
- 前台窗口句柄、标题和所属进程名称，用于决定是否暂停或拒绝输入。
- Esc、Shift、Ctrl、Alt、Win 的当前按下状态，仅用于停止及防止组合快捷键干扰。

使用 Windows Forms `SendKeys.SendWait` 逐字符发送输入。不会安装全局键盘记录钩子，不记录用户打字内容。正常运行不需要管理员权限。

## 程序不读取的数据

不读取浏览器用户目录、Cookie、登录凭据、密码库、Token、学生身份信息或其他文件；不自动扫描文本目录。不调用网站 API、不自动登录或提交、不使用剪贴板，没有遥测或联网代码。

用户自己选中的文件可能含个人信息，程序无法判断语义；分享前应检查内容。用户输入网页的文字会受该网站自己的自动保存和数据政策约束。操作系统可能保留文件选择历史、进程或错误诊断信息，不属于本程序主动记录。

## 数据存储与发行边界

用户文本不由程序复制到工程目录，退出后不保存进度。`config.local.json` 和 `data/` 已被 Git 忽略。发布脚本使用显式文件清单，不会枚举并打包使用目录中的其他文件。公开 `examples/sample.txt` 仅供演示，请勿替换成私人正文。

截图脚本仅为文档生成：打开加载公开样例的本项目窗口，通过 `DrawToBitmap` 保存该窗口图像，不截取整个桌面。若自行更换示例文件，生成的新截图也可能泄露内容。

## 技术边界

窗口标题可以伪造；程序没有域名、DOM、输入框或光标验证。相同标题的标签页切换可能不可见。检测到窗口变化和发送按键之间仍有竞态，因此用户必须保持焦点、先测试、再逐段核对。不要在密码框、单行提交框或敏感操作窗口使用。

受管设备可能限制 PowerShell、动态编译、Win32 API 或模拟输入。程序不会申请提权、修改安全策略或保证这些限制下可运行；请由设备管理员决定是否允许使用。
